# Whisky Loading Screen

**A lightweight, customizable FiveM loading screen by WhiskyDevelopment.**

Whisky Loading Screen combines a local MP4 playlist with real FiveM loading progress, a permanently displayed Discord staff team, and a separate roster of players currently in the server. The player roster can display framework character names, Discord guild nicknames, or FiveM player names.

> **Note:** This resource uses local MP4 files only. There is no YouTube integration, external video host, or external Node.js bot process.

## Features

- **MP4 video playlist** — multiple local videos, automatic next video, and playlist looping.
- **Playback controls** — previous, play/pause, next, and adjustable volume.
- **Blurred video background** with a large, centered PNG server logo.
- **Real FiveM loading progress** — uses FiveM's `loadProgress` event, not a fake timer.
- **Live server branding** — reads `sv_projectName`, with `sv_hostname` as the fallback.
- **Online player count** — shows the server's current player count and maximum capacity when a player connects.
- **Connected-player roster** — displays player names from Qbox, QBCore, ESX, Discord, or FiveM, depending on configuration.
- **Persistent Discord staff panel** — displays *configured staff* whether or not they are currently playing, with server nicknames, avatars, ranks, and fallback names.
- **Discord cache** — stores previously fetched staff information server-side for recovery from temporary Discord API failures and restarts.
- **Streamer Mode** — saves a per-client preference to mute videos and anonymize staff/player identities without removing the staff panel.
- **Server-side Discord configuration** — no bot token is exposed to the loading-screen page.
- **Cfx Asset Escrow-ready server modules** with an editable `server_config.lua`.

## Requirements

- A functioning **FiveM / FXServer** instance.
- **Qbox, QBCore, or ESX is optional.** Use `NameMode = 'fivem'` without a framework.
- A **Discord bot in your Discord server** is required to retrieve Discord staff names/avatars or display online players by Discord guild nickname. The rest of the loading screen can run without Discord integration.
- Local `.mp4` background videos and a `.png` logo.

No SQL database, extra framework dependency, YouTube API key, or separate Node.js process is required.

## Installation

1. Extract the resource into your FiveM server's `resources` directory, keeping the folder named `whisky-simple-loadscreen` (or use a different folder name consistently).
2. Open `server_config.lua` and configure your Discord bot/server, staff IDs, and player-list preferences.
3. Place your `.mp4` files and server logo in `html/assets/`.
4. Configure the video playlist in `html/media_config.js`.
5. Add the resource to your `server.cfg`:

   ```cfg
   ensure whisky-simple-loadscreen
   ```

6. Restart the server or start the resource from the server console. Join the server to test the actual FiveM loading screen.

**There is no `setr` or `set` requirement for the Discord bot token.** Keep the token inside the server-only config.

## Discord bot and staff setup

### 1. Create or use a Discord bot

1. Go to the [Discord Developer Portal](https://discord.com/developers/applications).
2. Create an application, then create/configure its bot.
3. Add the bot to your Discord server.
4. Copy the **bot token**, your **Discord server (guild) ID**, and the **Discord user IDs** for staff members.
5. Enable **Developer Mode** in Discord if you need the *Copy ID* option.

**Never share your bot token.** Do not upload an actual configured token to Tebex, GitHub, customer ZIPs, or screenshots. If a token was exposed, regenerate it in the Discord Developer Portal.

### 2. Edit `server_config.lua`

The bundled config uses the **original top-level format**, which this resource supports:

```lua
WhiskyLoadscreenConfig = {
    BotToken = 'YOUR_DISCORD_BOT_TOKEN',
    GuildId = 'YOUR_DISCORD_SERVER_ID',

    RefreshMinutes = 10,
    MaxVisibleStaff = 8,

    PlayerList = {
        Enabled = true,
        NameMode = 'framework',
        Framework = 'auto',
        DiscordFallback = 'framework',
        StartExpanded = true,
        ShowServerIds = true,
        MaxDisplayed = 80,
        DiscordCacheMinutes = 30
    },

    Staff = {
        { userId = '111111111111111111', role = 'OWNER',     fallbackName = 'Owner' },
        { userId = '222222222222222222', role = 'DEVELOPER', fallbackName = 'Developer' }
    }
}
```

Every Discord `userId` and `GuildId` should be a **quoted string**. Change the example values to your own IDs; do not leave fake IDs configured.

`RefreshMinutes` determines how often the staff module refreshes Discord information. The code enforces a minimum of **2 minutes**, so `0` does *not* disable refreshes. **10 minutes is a recommended starting point.**

The resource also supports the newer `StaffDiscord = { BotToken, GuildId, RefreshMinutes, MaxVisibleStaff, Members = {...} }` block. Use **one matching format**, rather than mixing old and new staff fields.

### How permanent staff works

The **SERVER STAFF** cards are created from configured staff IDs, **not** from players currently connected to FiveM.

- Staff do **not** have to be online.
- The panel remains visible with fallback cards if Discord is unavailable or an ID is missing.
- Real guild nicknames and avatars are fetched through Discord when possible.
- Successfully fetched profiles are cached using server KVP storage for future connections and server restarts.
- `html/staff_snapshot.js` stores **public display information only** for web previews. It may need refreshing after a successful Discord lookup.

You can request a fresh lookup from the server console:

```text
whisky_staff_refresh
```

The console can run this command; in-game execution requires appropriate ACE permissions.

## Connected-player roster

The player list is a **different system** from Discord staff. It uses players actually connected to FXServer, and it can be expanded/collapsed by clicking the online-player counter.

Configure it in `server_config.lua`:

| Setting | Options | Description |
|---|---|---|
| `Enabled` | `true`, `false` | Enables or disables the player roster. |
| `NameMode` | `'framework'`, `'discord'`, `'fivem'` | Controls which name is displayed. |
| `Framework` | `'auto'`, `'qbx'`, `'qb'`, `'esx'` | Selects framework for character names. |
| `DiscordFallback` | `'framework'`, `'fivem'` | Name to use when guild nickname is unavailable. |
| `StartExpanded` | `true`, `false` | Open or collapse the roster initially. |
| `ShowServerIds` | `true`, `false` | Display player server IDs beside names. |
| `MaxDisplayed` | Number | Limits entries shown in the roster, not the player count. |
| `DiscordCacheMinutes` | Number | Discord player nickname cache duration. |

**Name modes:**

- **`framework`**: Displays in-character first/last names from Qbox, QBCore, or ESX when available. If no character name is ready, it falls back to the FiveM player name.
- **`discord`**: Uses a connected player's nickname from the configured Discord guild when available; otherwise the configured fallback applies.
- **`fivem`**: Shows their FiveM player name.

**Important:** This release sends a **connection-time snapshot** of online players and their names to the joining client's loading screen. It is not a continuously updating roster while that person loads. The next joining player receives a newer snapshot. The staff panel remains independent of this behavior.

## MP4 playlist setup

1. Put your videos in `html/assets/`, for example `background.mp4`, `trailer2.mp4`, and `highlights.mp4`.
2. Edit `html/media_config.js`:

```js
window.WhiskyMediaConfig = {
    defaultVolume: 35,  // 0–100
    autoNext: true,
    loopPlaylist: true,

    playlist: [
        { src: 'assets/background.mp4', title: 'Welcome to the City' },
        { src: 'assets/trailer2.mp4', title: 'Server Trailer' },
        { src: 'assets/highlights.mp4', title: 'Community Highlights' }
    ]
};
```

Every playlist entry must point to a real file. Videos are served locally as part of the resource; no YouTube embeds are used.

**Recommended encoding:** MP4 container, H.264 video, and AAC audio for broad compatibility with FiveM's Chromium-based loading screen. For smoother loading, compress very large videos before adding them; 1080p is often a sensible balance of appearance and resource size. Test the files in FiveM, since successful playback in a regular browser does not guarantee identical behavior in every FiveM build.

To change the centered logo, replace `html/assets/logo.png` with your transparent PNG. Keeping the same filename avoids needing to edit HTML.

## Loading progress, server name, and player count

- The loading bar responds to FiveM's own `loadProgress` events. It does not invent percentages when events are unavailable.
- Server name is taken from `sv_projectName`, or from `sv_hostname` if no project name is configured.
- Player count and maximum slots are gathered server-side during connection handover.
- Open the connected-player list by clicking the player count (if enabled).

A plain web preview **does not have FiveM handover data**. Online player count, roster names, and real load progress must be tested during an actual server connection. Staff profiles may still appear in a web preview if a generated snapshot is present.

## Streamer Mode

Click the **settings gear icon** near the server information and enable **Streamer Mode**.

When enabled, the loading screen:

- Mutes the background video's audio.
- Hides staff names and profile pictures while leaving staff cards visible.
- Anonymizes connected-player names/identities.

The toggle is saved in the client's browser `localStorage`, so it can be restored on future loads as long as the client's browser storage is retained. Clearing client cache/browser storage may reset the preference.

## Cfx Asset Escrow / commercial distribution

`fxmanifest.lua` includes the private server logic as server scripts and excludes the editable config from escrow:

```lua
server_scripts {
    'server_config.lua',
    'server/staff.lua',
    'server/players.lua',
    'server/handover.lua'
}

escrow_ignore {
    'server_config.lua',
    'html/staff_snapshot.js'
}
```

When publishing through **Cfx Asset Escrow**, the Lua modules under `server/` can be protected while `server_config.lua` stays editable. Front-end HTML/CSS/JS files remain readable; do not put secrets in them.

**Before publishing/selling:**

1. Replace any real Discord token, guild ID, and staff IDs in your distribution copy with placeholders.
2. Remove any real names/avatars from `html/staff_snapshot.js` if you don't intend to distribute that public data.
3. Test the *customer ZIP* on a clean server after inserting a test bot token and IDs.
4. Keep a backup of your personal configured `server_config.lua` when updating the resource.

## Troubleshooting

| Problem | What to check |
|---|---|
| Staff panel shows placeholders | Verify bot token, guild ID, membership in the Discord server, and staff user IDs. Check server-console logs, then run `whisky_staff_refresh`. |
| Staff disappears in a browser preview | Ensure the preview uses the current `html/staff_snapshot.js` generated by the server; refresh the preview. The staff panel itself should retain fallback slots. |
| Discord usernames do not populate | Check Discord bot authorization and whether those user IDs belong to the configured guild. First successful lookups are required for cached real profiles. |
| Character names show FiveM names instead | Check whether Qbox/QBCore/ESX is started and the player has loaded a character. Verify `NameMode` and `Framework`. |
| Player roster is empty in a static browser preview | Expected: player information comes from a real FiveM connection, not from static HTML. |
| Player list seems outdated | Expected in this release: it is a snapshot captured when joining. |
| MP4 is black or fails to start | Verify filenames/playlist paths and re-encode the file with H.264/AAC. Test the MP4 directly in FiveM. |
| Streamer Mode setting does not persist | Check whether FiveM/client browser storage was cleared or reset. |
| Loading bar has no percentage in a web preview | Expected: actual percentages require FiveM `loadProgress` events. |
| A resource update reset bot/staff settings | Restore the backed-up `server_config.lua` or copy the values into the updated example config. |

## Notes

- This resource is designed for FiveM's loading-screen browser, not a standalone in-game NUI menu. The loading screen should close automatically when FiveM completes loading.
- It does not use `backdrop-filter`, WebAssembly, or the YouTube iframe API.
- Discord profile/avatar availability depends on the Discord API, your bot's access, and network connectivity.
- You are responsible for using videos, audio, and logos you have the rights to distribute or display.
